# Install Streamloom

Live TV for your phone and TV. Share this page: **https://streamloomdownloads.github.io/streamloom-downloads/**

Pick how you want to install it.

## 1. Google Play early access

Prefer Play Store updates? You need the Google account you use on your phone.

1. [Join the early access group](https://groups.google.com/g/streamloom-early-access/about) (free, approved automatically). Sign in with your Google account and tap *Join group*.
2. [Open Streamloom on Google Play](https://play.google.com/store/apps/details?id=com.softarchium.streamloom) and tap *Install*. It can take a few minutes after joining before the button appears.

Play updates arrive automatically. A copy installed from Play can't be updated by the direct downloads below, and the other way round, so stick to one.

## 2. Fire TV, Fire Stick, Android TV

Not using Google Play? On a TV, install with the free **Downloader** app.

1. Install **Downloader** (orange icon) from your TV's app store.
2. **Fire TV:** open *Settings → My Fire TV → Developer options → Install unknown apps* and turn on Downloader. **Android TV:** when asked, allow Downloader to install apps from this source.
3. Open Downloader, enter the code **`3316691`**, then choose *Go*.
4. When the download finishes, choose *Install*, then *Open*.

Code not working? In Downloader's address box, type:
`https://github.com/StreamLoomDownloads/streamloom-downloads/releases/download/stable/streamloom.apk`

## 3. Android phone or tablet

Not using Google Play? Download the app directly.

1. [Download Streamloom (APK)](https://github.com/StreamLoomDownloads/streamloom-downloads/releases/download/stable/streamloom.apk) (about 5 MB, needs Android 7.0 or newer).
2. Open the downloaded file. If Android says it is blocked, tap *Settings* and allow installs from your browser (or Files app), then go back.
3. Tap *Install*, then *Open*.

## Updating

Play installs update on their own. For a direct download, install the newest file the same way: it updates over your existing copy and keeps your favourites and history, and the download link always points to the latest version.

## Trouble?

- **"App not installed":** make sure you have a little free space, and uninstall any older copy that came from somewhere else, then try again.
- **Can't find Downloader:** search for it by name in your TV's app store.

## 4. Watch in your browser

No install needed. Works on any phone, tablet or computer: **[streamloom.softarchium.com](https://streamloom.softarchium.com)**
